# North Garage Traffic Dashboard

Open `dist/index.html` in a modern browser, or serve the `dist` directory with any static web server. All values are simulated; no physical signs, sensors, or cameras are controlled.

The simulation advances manually in configurable phase increments and wraps after phase 3. Advancing reduces occupancy by 15 percentage points on the outgoing phase's EXIT floors and updates the illustrative queue and delay. Click a phase to select it and adjust its duration in minutes; subsequent phase time windows update automatically. Click a phase to select it, click a floor signal to toggle EXIT/WAIT, select floors and add a custom phase, or delete the active phase while keeping at least one. Reset restores the initial state and removes custom phases and signal changes. Turning event egress off pauses the simulation and displays inactive signals.

For future integration, replace the initial simulation adapter in `dist/app.js` with a normalized snapshot provider for sensor data or SUMO output. Define floor capacity and measured occupancy per floor before calculating a capacity-weighted total; the current demonstration assumes equal floor capacity. The garage capacity is 1,500 vehicles. The occupied vehicle count assumes equal floor capacities; the simulated queue stays at least one until every floor is empty. Queue and delay are illustrative, not traffic predictions. Add a backend and appropriate authorization before connecting operational equipment.
